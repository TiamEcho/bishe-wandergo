🧮 算法说明（毕业设计答辩要点）
· UserCF：对用户-景点评分矩阵按行做 余弦相似度，取 Top-10 相似用户，加权预测目标用户对未交互景点的评分 → sim(u,v)=Σ r_ui·r_vi / (√Σr_ui²·√Σr_vi²)
· ItemCF：按列计算景点间共现相似度，用用户已评高分的景点加权推算相似景点
· 融合：score = 0.5×UserCF + 0.5×ItemCF；无评分行为时自动降级为「热度 × 评分」热门兜底，解决冷启动
· 后端由 Spring Boot + MyBatis-Plus 实现同款算法（D:\wandergo-backend），评分存 MySQL rating_record 表；前端离线时用同一套种子矩阵本地演示
